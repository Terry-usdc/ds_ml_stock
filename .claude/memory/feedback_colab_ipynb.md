所有撰寫的代碼必須存成 `.ipynb`（Jupyter Notebook）格式。

**Why:** 使用者在 Google Colab 上訓練模型，需要 notebook 格式才能直接上傳執行。

**How to apply:** 凡是寫代碼給使用者，一律產出 `.ipynb` 檔案，而非 `.py` 腳本或 markdown 代碼區塊。
